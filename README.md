# 永久投资策略回测

这是 `portfolio_backtest_implementation_plan.md` 的落地实现：Python + SQLite 后端、单页面 JavaScript + ECharts 前端。

## 安装与启动

在仓库根目录执行。需要 Python 3.11 或以上版本、`venv` 和 `curl`。Ubuntu 如缺少虚拟环境组件，先安装与 Python 版本对应的 `python3-venv` 包。

Windows PowerShell

```powershell
py -3.11 scripts/install.py
$AppPython = '.\.venv\Scripts\python.exe'
& $AppPython -m app.main --port 51327
```

Linux

```bash
python3 scripts/install.py
.venv/bin/python -m app.main --port 51327
```

安装脚本创建或复用 `.venv`，安装运行依赖，首次复制 `.env.example` 为 `.env`，并初始化或升级 SQLite 数据库。在已有环境重复执行会沿用 `.env` 和数据库。可用 `--venv` 指定虚拟环境路径，脚本完成时会打印对应的启动命令。服务启动后打开 [本机回测页面](http://127.0.0.1:51327/)。

## 数据库维护

`.env` 中配置 `TUSHARE_TOKEN` 后可下载所需行情。`DATABASE_PATH` 默认指向仓库下的 `data/backtest.sqlite3`，环境变量中的相对路径也以仓库为基准。安装、初始化、同步和启动均可用 `--db-path` 指定同一个数据库，命令行相对路径以运行命令的目录为基准。

以下以 PowerShell 为例。Linux 将 `& $AppPython` 换成 `.venv/bin/python`。

```powershell
# 任选需要的维护操作
& $AppPython scripts/init_db.py --db-path data/backtest.sqlite3
& $AppPython scripts/init_db.py --db-path data/backtest.sqlite3 --check
& $AppPython scripts/init_db.py --db-path data/backtest.sqlite3 --backup ..\backtest-before-upgrade.sqlite3
& $AppPython scripts/sync_data.py --db-path data/backtest.sqlite3 --start 2012-01-01 --end 2026-11-17
```

`--check` 只读检查现有数据库的结构和完整性。升级已有库时可加 `--backup`，先保存一致的 SQLite 副本，目标须是尚未存在的文件。数据库升级保留行情与历史回测。

同步脚本输出 JSON，列出补录数量、数据状态和还缺的项目。数据补录与回测缓存失效在同一事务提交。补录后仍有缺口时，脚本保留已成功补录的数据并以非零状态退出。

## 数据源

- 国内 ETF、沪深300、基金分红、复权因子：优先 Tushare HTTP API，需要 `TUSHARE_TOKEN` 环境变量。
- US ETF：VOO 使用 Yahoo 日线，失败后尝试 Eastmoney、Nasdaq、Stooq 等公开行情；价格只统一拆股单位，现金分红单独记账。Eastmoney 的未分红复权行情按 VOO 2013-10-24 的 1 合 2 拆股统一历史价格单位，避免切换来源时价格减半。
- 03195.HK 采用香港券商交易口径。它于 2024-04-23 在香港上市，上市前保留现金。分红以恒生投资官方资料为准。港股通名单及准入条件可在港交所查询。[港交所互联互通名单](https://www.hkex.com.hk/mutual-market/stock-connect/eligible-stocks/view-all-eligible-securities?sc_lang=en)
- 国债逆回购：依次使用 DataSrc、Sohu、Tushare、AKShare、东方财富 HTTPS 行情补齐每个缺失日期，部分返回不会阻断后续来源。204001 必须覆盖全部所需交易日。
- 较长期限逆回购的早期成交可能稀疏。只有 Tushare 完整的全市场历史快照能确认“204001 当天有报价，而所选品种当天无报价”，并且距今至少 7 天，才记录 `sync_coverage/repo_no_quote`。这些日期使用当天真实的 204001 利率和一天期限，不生成所选期限的伪报价，也不沿用它之前的利率；普通缺数、接口失败、截断响应及近期缺口仍会阻止回测。
- 汇率：按启用资产补齐 `USD/CNY`、`HKD/CNY` 等币种对，使用 DataSrc、Yahoo、外汇管理局中间价、Frankfurter、Stooq 等来源。外汇管理局的每 100 外币报价换算为每 1 外币人民币价，并明确记录中间价来源，可补齐海外休市而中国开市的日期；全部失败仍返回缺数据。
- 数据同步失败不会静默伪装成功，状态表会显示 `source`，同步返回会包含 `warnings` 和 `missing_data`。生产同步不会生成 mock/估算行情。
- 交易日历：通过 Tushare 的 `trade_cal`、`hk_tradecal`、`us_tradecal` 按市场、按年缓存到 SQLite，缺少年份时自动补齐。缺口检查和行情、逆回购、汇率同步均按实际开市日判断；周末和节假日沿用最近已发布交易日的数据。日历不完整时会明确报缺少交易日历，不会把没有行情的日子猜成休市，也不会放宽真实交易日的缺数检查。
- 数据检查会核对区间中间的交易日缺口，自动补数也会修复这些缺口。已写入的数据与回测缓存失效一起提交；其他数据源失败或请求取消不会留下仍然有效的旧缓存。
- 518880 的场内行情从 2013-07-29 上市日开始，之前继续使用已标注来源的 Au99.99 历史代理。基金复权因子独立下载，不会因某次行情请求为空而跳过；逆回购历史缺口增加 Tushare `repo_daily` 来源。
- 宽基 ETF 增加中证A50（平安 159593），2024-03-12 起使用真实 ETF；之前自 2014-12-31 起使用中证官方 930050 价格指数代理，并扣除 0.20% 年费用，真实 ETF 阶段不重复扣费。海外日历只要求资产实际历史区间；缓存中出现美股或港股周末开市记录时，重新获取该年完整日历。
- 513500 从 2014-01-15 上市日起使用真实行情；2022-03-29 因 1:2 份额拆分全天停牌，缺口检查、补数及交易均排除该基金的此日期，其他资产仍按市场日历正常交易。拆分使用官方比例，避免将供应商复权因子误当份额比例；不会补造停牌日行情。
- 512890 于 2021-10-22 因 1:2 份额拆分全天停牌，10-25 复牌。补数与交易均排除停牌日，复牌时按拆分比例衔接持仓价值。
- 512100 在 2022-09-02 停牌合并份额，9 月 5 日复牌。按公告比例 0.36555 换算持仓并将碎份向上取整。[基金份额合并公告](https://www.sse.com.cn/disclosure/fund/announcement/c/new/2022-09-05/512100_20220905_1_UJdHwEYe.pdf)
- 华宝添益 511990 分别记录场内成交价与每百份收益。收益分配按收盘持仓计算，整百元转成份额，全部卖出后结算剩余现金。[华宝基金业务说明](https://www.fsfund.com/finaSchool/cjwt.shtml)
- 周期再平衡用各市场的真实开盘报价作为成交参考。中债、中证官方收盘指数及场外基金净值代理使用开盘前最近已公布值。缺真实执行报价时，对应交易顺延。境内与美股按时段处理，美股晚间卖出资金最早在后续境内交易时段使用。除息时确认应收，支付日成交结束后释放无盘中到账时间的美股分红。ETF 份额拆合使用发行人公布的事件日期和份额比例。

## 逆回购计息

2017-05-22 起，利息按首次资金交收日（含）到到期资金交收日（不含）的自然日数计算，年基数为 365；此前按名义期限和 360 天计算。到期资金可用于交易的清算日，与计息截止的资金交收日分开处理。例如普通周四的一天期回购计息 3 天，周五的一天期计息 1 天；节假日按交易日历顺延。规则参考：[上交所 2017 年回购新规说明](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20170519_4313753.shtml)。

沪市逆回购从 2022-05-16 起按 1,000 元申报档位计算，更早的历史交易按 10 万元档位。用于计算超额收益的现金基准一直使用 204001，并按成交、到期及佣金记账。[上交所规则实施日期](https://bond.sse.com.cn/lawrule/sserules/trading/c/5702698.shtml)

## 费用口径

页面把费用拆成两类：

- 可调整费用假设包括券商佣金、换汇点差、美国分红预扣税和单边滑点。A 股、港股、美股 ETF 的默认滑点分别为 5、10、3 个基点。滑点计入买卖成交价，汇总中单独披露。
- 固定费率与成本对照：交易所/监管规费、结算费、基金内扣费率等当前按公开规则固化的假设。

## 页面操作与结果口径

设置保留连续表单：**回测范围和调仓规则 → 现金与消费池 → 资产配置 → 费用**。桌面保留左侧参数区，手机用可关闭的参数抽屉；运行按钮始终可达。容忍带、现金比例、补仓阈值和资产上限支持滑杆与百分比数字双向输入。

修改参数不会立即重算。页面明确区分“当前编辑参数”与“当前显示结果使用的参数”，有差异时显示“参数待应用”。点击运行后，三个运行入口共同锁定，完成后同时恢复。输入日期、金额或权重有误时会定位到对应控件；失败信息在结果区可见。

结果依次展示四个核心指标、检查与实际调仓统计、图表、风险明细、逐笔记录。费用、消费、现金分红、收益计算口径和代理行情说明保留在可展开的二级信息中。数据状态显示缓存范围，运行时仍会验证本次策略所需的实际覆盖，不能仅以缓存的最晚日期判断数据完整。

结果显示主组合及对照行情各自的有效截止日。对照组合使用相同的换标与成交引擎，到首个未核实的数据缺口前停止绘制。单日收益图使用完整交易日序列。

### 调仓频率为什么可能不改变收益

每日、每周、每月、每季度、每半年和每年决定的是**检查频率**。检查时只有权重超出相对容忍带才触发调仓；恢复目标权重开关决定成交后的目标，不会跳过容忍带条件。首次建仓单独按目标配置，不受容忍带阻挡。逢低补仓及年度月份对比仅在年度频率下生效。

结果分别统计周期检查、实际调仓、带内无需调仓及成交条件不足。建仓和现金标的启用单列。再平衡记录显示每次周期检查，带内检查标明“带内，无需调仓”和零笔成交。相同交易日的自动换标成交单列，显示卖出与买入的标的。点击记录日期可定位曲线、查看明细和当日交易。随页面上下滚动查看记录，表头移到顶部后固定在导航栏下方。遇休市或缺少真实开盘报价时，沿用原有延期执行规则。

固定消费池按执行时总资产换算目标权重，保持固定金额含义。全部资产关闭时预览和引擎都将资金分配到现金管理。每月消费不足时只提取可用资金，结果明确展示计划金额、实际金额、缺口及首次不足日期。

### 保存结果、对比与导出

最近记录支持查询、排序、回放和删除；方案可命名、收藏和备注，收藏视图也能找回最近 20 条以外的方案。命名、备注、收藏和榜单按 Key 隔离，行情与历史回测仍共享。方案对比展示双方日期、参数差异、费用和实际调仓次数；区间不同时明确提示，可重新计算公共区间。查看历史保留未运行草稿；通过“用此参数修改”可将保存方案载入编辑区再运行。快速切换历史时只显示最后一次选择；删除当前记录同时清除图表、摘要和记录，避免误认为删除后的结果仍有效。

滚动窗口和已开启的月份对比在主结果后补齐。服务重启后重新打开未完成记录会恢复分析，失败可单独重试；不必重复生成主体结果。旧引擎历史允许查看和导出，但会提示重算；不与新引擎进行策略诊断比较。

CSV 从当前保存结果读取配置、时间范围和资产，修改尚未运行的参数不会改变导出内容。可调整日期及勾选标的，错误日期纠正后可继续导出。

### 批量研究

研究固定当前已保存回测的配置，不使用尚未运行的草稿。频率 × 容忍带比较和消费压力测试均调用同一个真实回测引擎，每次最多 24 个情景，可查看进度、取消和逐行失败原因。结果不加入普通历史或榜单，不自动下载外部行情；本地数据不完整时提示先补齐基准区间。旧引擎结果需重新运行后才能研究。

消费压力测试组合每月金额、年增长率和起始年份，展示首次提取不足日期、缺口、实际消费与剩余资产。年增长率默认 0，前 12 个提取月份金额相同，第 13、25…个月递增；不同起始年份沿用基准月日（闰日适当调整）及结束日，回测时长会不同。收益率剔除消费现金流。年度专属的逢低补仓仅在年度频率的情景中执行。

## 回归验证

```powershell
& $AppPython scripts/run_tests.py
npm ci
npm run test:ui
npx playwright install chromium webkit
npm run test:e2e
```

测试脚本使用标准库 `unittest` 和 `trace` 统计 `app/` 下业务代码覆盖率，低于 90% 会失败。

前端行为测试覆盖乱序响应、重复运行、删除后的清理、非年度规则、CSV 结果绑定及研究/方案交互。后端测试覆盖真实情景计算、消费增长与缺口、任务取消、元数据隔离等。Playwright 会启动真实 HTTP 服务并生成隔离的 SQLite 数据库，分别检查电脑、手机及小屏 WebKit；测试结束后删除临时数据库，报告与截图保存在 `output/playwright/`。不向正式历史写入测试结果。Windows 默认使用 `py -3.11`，其他平台使用 `python3`；可用 `PORTFOLIO_TEST_PYTHON` 指定命令、`PORTFOLIO_E2E_PORT` 更换测试端口。
