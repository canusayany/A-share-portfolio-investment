## 数据源

- 国内 ETF、沪深300、基金分红、复权因子：优先 Tushare HTTP API，需要 `TUSHARE_TOKEN` 环境变量。
- US ETF：优先 Stooq 日线公开 CSV。
- 港股通 ETF（如 03195.HK）：优先本地 DataSrc 缓存，失败后使用 Yahoo/Eastmoney 公开行情；分红优先 Yahoo。
- 国债逆回购：优先 AKShare `bond_buy_back_hist_em`，失败后使用东方财富 K 线公开接口；全部失败则返回缺数据。
- 汇率：按启用资产补齐 `USD/CNY`、`HKD/CNY` 等币种对，优先本地 DataSrc，失败后使用 Yahoo、Frankfurter、Stooq 和公开 currency API；全部失败则返回缺数据。
- 数据同步失败不会静默伪装成功，状态表会显示 `source`，同步返回会包含 `warnings` 和 `missing_data`。生产同步不会生成 mock/估算行情。
- 交易日历：通过 Tushare 的 `trade_cal`、`hk_tradecal`、`us_tradecal` 按市场、按年缓存到 SQLite，缺少年份时自动补齐。缺口检查和行情、逆回购、汇率同步均按实际开市日判断；周末和节假日沿用最近已发布交易日的数据。日历不完整时会明确报缺少交易日历，不会把没有行情的日子猜成休市，也不会放宽真实交易日的缺数检查。
- 数据检查会核对区间中间的交易日缺口，自动补数也会修复这些缺口。已写入的数据与回测缓存失效一起提交；其他数据源失败或请求取消不会留下仍然有效的旧缓存。
- 518880 的场内行情从 2013-07-29 上市日开始，之前继续使用已标注来源的 Au99.99 历史代理。基金复权因子独立下载，不会因某次行情请求为空而跳过；逆回购历史缺口增加 Tushare `repo_daily` 来源。
- 周期再平衡只使用各市场当天可用的开盘报价。休市或缺少开盘价时，整次再平衡顺延，并保留待交易现金；原持仓继续按最近已发布价格估值。中国假期内的海外除息事件会在下一次估值、交易前补记，使用除息日已知汇率及当时持仓，到账仍遵循各笔分红的支付日期。

## 逆回购计息

2017-05-22 起，利息按首次资金交收日（含）到到期资金交收日（不含）的自然日数计算，年基数为 365；此前按名义期限和 360 天计算。到期资金可用于交易的清算日，与计息截止的资金交收日分开处理。例如普通周四的一天期回购计息 3 天，周五的一天期计息 1 天；节假日按交易日历顺延。规则参考：[上交所 2017 年回购新规说明](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20170519_4313753.shtml)。

## 费用口径

页面把费用拆成两类：

- 可调整费用假设：券商佣金、换汇/出入金点差、港股通汇兑点差、美国分红预扣税。
- 固定费率与成本对照：交易所/监管规费、结算费、基金内扣费率等当前按公开规则固化的假设。

03195 与 VOO 的主要默认口径：

| 项目 | 03195 港股通 | VOO 美股 |
| --- | ---: | ---: |
| 基金内扣费用 | 0.79%/年 | 0.03%/年 |
| 基金费用差 | 03195 每年多约 0.76% | - |
| 官方交易规费 | 0.0085%/边 | SEC 卖出 0.00206% |
| 结算/交收费 | 0.0042%/边 | FINRA TAF 0.000195 美元/股，上限 9.79 美元 |
| 印花税 | ETF 暂按 0 | 0 |
| 持仓组合费 | 港股通 0.008%/年，按日折算 | 0 |
| 分红税 | 多体现在基金净值/跟踪差 | 默认按最差预期 30%，可在页面调低 |

注意：真实 ETF 阶段的基金内扣费用已经体现在基金净值或历史价格中，回测不额外重复扣除；这里只作为成本对照展示。上市前若使用不含基金费用的指数代理，则必须单独加入对应 ETF 的费用拖累：512890 的 H20269 全收益指数代理阶段按其上市初期合同口径，扣除管理费 0.50% + 托管费 0.10% + 指数使用费 0.03% = 0.63%/年，并在真实 ETF 开始交易后停止，避免重复收费。2025-03-21 起指数使用费改由基金管理人承担，但该变化发生在真实 ETF 阶段，已自然反映于后续价格。03195 的管理费、受托人费等属于 0.79% 经常性开支内部结构，不与 0.79% 重复相加。券商佣金、换汇点差、出入金和盘口价差因账户与下单时点不同，页面保留为可调整假设。

主要参考：恒生投资 03195 产品资料、Vanguard VOO 产品资料、HKEX 交易规费、SEC Section 31、FINRA TAF、IBKR 美股佣金。
